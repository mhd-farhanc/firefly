</p>

---

## 🚀 Features

- **Real-time Messaging** — Instant delivery using Cloud Firestore streams.
- **Secure Authentication** — Email & password login/signup powered by Firebase Auth.
- **Friend System**
  - Search for users by username.
  - Send, accept, and reject friend requests.
  - "Pending Request" notification system.
- **Custom UI/UX**
  - Dark mode by default (industrial black & red theme).
  - Custom fonts (DotGothic16) and sharp-edged styling.
  - Auto-scrolling chat interface.

## 🛠️ Tech Stack

- **Frontend:** Flutter (Dart)
- **Backend:** Firebase (Firestore, Authentication)
- **State Management:** Provider
- **Design:** Google Fonts (Inter & DotGothic16)

## 🏁 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mhd-farhanc/firefly.git
   ```
2. **Install dependencies:**
   ```bash
   flutter pub get
   ```
3. **Firebase Setup:**
   Configure your own Firebase project:
   ```bash
   flutterfire configure
   ```
4. **Run the app:**
   ```bash
   flutter run
   ```
